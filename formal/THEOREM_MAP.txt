Fixed-depth theorem
  MainProblem.lean: FixedProblem contains the original input assumptions.
  MainPreparedProgram.lean: preparedFixedDepthProgram is the executed program.
  MainFeasibleKernel.lean: fixed_depth_from_feasible_kernel_polylog.
  This is the direct caller from any genuinely feasible multiplication
  family. It constructs the classical safeguard internally.
  MainFinalStatements.lean:
    fixed_depth_tradeoff_polylog
    fixed_depth_tradeoff_narrow_polylog
  These include all-outcome width/rank, explicit C=UV, admissibility, input
  reads, factor/dense output entries, Gaussian draws, all arithmetic, and
  the constructed measurable success event of probability at least1-delta.
  The cost displays the input, coarse Gram, core, true action, weighted fine
  action, dense output, and conditional wider-basis terms. The prefactor
  is proved bounded by (Ck+1)*C_L*Z^(2L+4), where Z contains only logarithms
  of the supplied dimensions, accuracies and failure probability.
  MainFeasibleKernel.lean constructs the classical safeguard from any given
  feasible arithmetic-kernel family; it is not an extra input assumption.

Growing-depth theorem
  MainFamilyProgramFinal.lean: growingDepthProgram_family_theorem.
  MainFamilyRuntimeFinal.lean: growingDepthProgram_paper_runtime.
  Exact interval: 1/8<d<(sqrt(2)-1)/2. The same program computes its schedule,
  handles the finite no-level case, returns the original relative accuracy,
  and has actual explicit-output work N^(2+o(1)). The kernel family is fixed
  before the requested asymptotic epsilon. The stronger unfolded bound is
  included separately; it does not raise the kernel overhead to the depth.

Optimized comparison corollary
  CorollaryOptimizedFinal.lean: optimized_paper_corollary.
  Includes the actual hierarchical N^(2+o(1)) algorithm and both actual
  comparator N^(2+s_*+o(1)) upper bounds, their error probabilities,
  all-outcome width/rank/factorizations, and total explicit-output work.
  The implementations are fixed before the input family and asymptotic
  epsilon. Exact d_*, alpha_*, s_*, accuracy and rank exponents, and the
  maximal stated saving are proved together. These are upper bounds;
  the result does not assert a lower bound on competing algorithms.

The input consists of two graph conductance Laplacians with the same
positive diagonal masses and one existing edge conductance increased.
In symmetric mass-normalized coordinates E=B-A=ww^T, ||w||=1. Supply
0<h<=1 with promise B<=(1+h)I. For fixed 0<alpha<1 the algorithm
returns general thin factors for D=B^alpha-A^alpha with operator error
at most epsilon, probability at least 1-delta, and expected
  ~O_alpha(M+N)
arithmetic INCLUDING all returned factor entries. Suppressed factors
are logarithmic in N,1/epsilon,1/delta; no mass ratio, spectral gap,
endpoint condition number or log(1/h) is suppressed.

With l=log(1/epsilon), b=log(1/h), the width is uniformly at most
  Phi_alpha(l,b)+O_alpha((l+1)^(15/8)),
where beta=1-alpha and
  Phi_alpha(s,b)=0,                         s<=alpha*b;
                (s-alpha*b)^2/(4*pi^2*alpha*beta), alpha*b<=s<=b;
                (s^2/alpha-b^2)/(4*pi^2),   s>=b.
Consequently h=epsilon^tau gives the sharp leading coefficient
C_alpha(tau) proved in fractional-boundary-crossover.txt. The matching
strict-count lower already holds on connected paths with arbitrary
positive masses. This certifies optimal leading width, not optimal runtime.

If epsilon<=1/2 and h^alpha<=epsilon/2, a second branch returns an
actual PSD rank-one correction with the same expected work. It applies
eventually for fixed tau>1/alpha. No exact width-one algorithm at the
transition equality tau=1/alpha follows from its error budget.

Exact arithmetic uses field operations, comparisons, scalar square roots
and randomness, with fixed alpha supplied as a constant. Scalar series
charge all node exponentials and fixed constants. This no-power-oracle
claim concerns the NORMALIZED input ||E||=1; it does not silently supply
an arbitrary physical scale ||E||^alpha. General returned factors need
not be symmetric. Dense expansion is an additional cost. No finite-word
stability, bit complexity or deterministic runtime cap is asserted.

# Frozen separated-case inputs for batch 060

## Separation boundary

Any distance tending to infinity between distinct attachment labels gives the
already accepted asymptotically separated model. Keep that proof fixed. New work
must extend the resolvent and root analysis to bounded patterns, not redefine the
old model until it appears correct for those patterns.

If a new computation exposes a genuine error in an old proof, preserve its original
file and write a separate erratum with the exact error, affected theorem and reviewed
replacement. Do not edit the old proof silently to make the two models agree.

## Non-negotiable reuse rules

- Fixed labels in batch 050 produce asymptotically separated sets, not clustered ones.
- The full Kesten-McKay transform is used, not the one-sided branch.
- Host-Perron decomposition and host-eigenvalue multiplicity stay explicit.
- Numerical raw outputs are corroboration only. No new result can merely point at
  batch 050's numerical agreement and infer a clustered root law.
- Do not extend the nonintegral $\lambda_f=d$ exclusion beyond its separated-model
  setting. A pattern-dependent equality must be verified independently.

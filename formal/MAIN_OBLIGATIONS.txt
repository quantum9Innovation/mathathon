Fixed-depth theorem: explicit finite statement

Inputs and original model assumptions:
  n,m,p,r,L : Nat, m<=min(n,p), 1<=r<=m, 1<=L;
  A : Matrix (Fin n) (Fin m) Real;
  B : Matrix (Fin m) (Fin p) Real;
  theta,delta : Real, 0<theta, 0<delta<1;
  h : Fin (L+1) -> Real with theta<=h[L], h[0]<=1/64,
      every h[j]>0 and h[j+1]/h[j]<=1/1024.
  Verified arithmetic matrix-multiplication kernels, symmetric in their
  three tensor dimensions, with a feasible square exponent omega>2 and
  fixed positive slack zeta; a claimed feasible exponent is a program
  witness plus correctness and work bounds, not an unproved cost function.

Required constructed object:
  A randomized exact-real arithmetic algorithm on A,B,r,theta,delta,h,
  counting field operations, comparisons, positive scalar square roots,
  Gaussian samples, preprocessing, range algebra and all output entries.
  It returns w<=r, U : Matrix (Fin n) (Fin w) Real,
  V : Matrix (Fin w) (Fin p) Real, and explicit C : Matrix (Fin n) (Fin p) Real
  with C=U*V. Any all-outcome width guarantee must be stated as such.

Required success event:
  Measure{outcome | ||A*B-C||_2 <=
      (1+theta)*tailSingularValue (A*B) r} >= 1-delta.
  Here tailSingularValue is the existing ZERO-indexed singular value,
  exactly paper sigma_(r+1), including extension by zero.
  No exclusion of deficient factors, repeated values, zero products,
  zero optimal tails, empty returned bases or rank loss is permissible.

Explicit constants and query width:
  Bj=2^(j+1); C0=36; C(j+1)=100(Cj+1);
  A_L=10^6(C_L+1); alpha=theta/(A_L*h[L]);
  capped q=softO(alpha^(-1/2)), with covariance-condition logarithm;
  wK=(2q+1)(r+1).

Full all-outcome cost, when wK<=m:
  softO_L(I+G_h0+m^(omega+zeta)
    + A_cost(r+1)*sqrt(hL/theta)
    + sum[j=1..L] J_cost(hj,r+1)*h[j-1]/sqrt(hL*theta)
    + n*p + T_MM(n,r,p)).
  I=m(n+p), A_cost(b)=T_MM(n,m,b)+T_MM(p,m,b).
  J_cost(h,b)=T_MM(sA(h),m,b)+T_MM(sB(h),m,b),
  sA=min(n,softO(m/h^2)), sB=min(p,softO(m/h^2)); row counts include
  failure budgets, and the identity-embedding fallback retains factors
  and charges their original actions. G_h charges only actual Gram formation.
  For arbitrary wK add m*wK^2. All degrees, repetitions, queries,
  factorization fallbacks, and bad-event outcomes require finite caps.

Growing-depth theorem: quantified family statement

  Fix d in the exact interval above and c_delta>0.
  Take integer dimension families m,N with m tending to infinity and
  log(N)/log(m) -> 1+d (equivalently N=m^(1+d+o(1))).
  n=p=N, rho=m/N, theta=rho^2*sqrt(rho),
  1<=r<=floor(sqrt(m)), m^(-c_delta)<=delta<1.
  The theorem must construct the manuscript's scalar square-root schedule,
  including its finite no-level fallback, with depth O_d(log log m).
  The SAME finite approximation algorithm must satisfy the same width
  and spectral error guarantee and total explicit-output cost N^(2+o(1)).
  Stronger explicit intermediate bound required by the manuscript:
    N^2*chi(m)*exp(O_(d,c_delta)((log log m)^2))
       +m^(omega+zeta)*(log m)^O_(d,c_delta)(1),
  where chi(m)=m^o(1) comes from a fixed-shape verified kernel and zeta
  is fixed below the positive margin 2+2d-omega. The endpoint omega<=9/4
  and the rectangular input/output kernel bound need actual proof witnesses.

Corollaries are separate obligations

  optimized: d*=(3sqrt5-5)/10, alpha*=(3sqrt5-5)/2,
    s*=(7-3sqrt5)/8; total N^(2+o(1)) for r<=sqrt(m), and both
    fully realized comparator upper bounds have exponent 2+s*.
    Existing scalar exponent identities alone do not prove this.
  absolute: supplied e>0, no supplied rank; define the least r_e in
    {0,...,m} with sigma_(r_e+1)<=e/(1+theta). Construct output width
    <=2r_e and error<=e with probability>=1-delta. On the SAME event
    obtain N^(2+o(1)) time when r_e<=floor(sqrt(m))/2, including r_e=0;
    other outcomes have finite caps and an actually constructed fallback.
  twolevel: N=m^(59/50+o(1)), h0=m^(-7/100), h1=m^(-1/12),
    theta=m^(-11/25), r<=ceil(m^(14/25)); construction exponent
    6724/3363 in N and full explicit-output exponent two, with rounded
    scalar-computable parameters and raw-width condition.
  exact Gram appendix: actual exact-field characteristic polynomial,
    random nonsingular congruence, LDL/rank/inertia, dual lift and complete
    arithmetic cost. No SVD, Ritz, root-isolation or sign-count oracle.

Dependency graph and closing evidence

  Existing checked scalar polynomial, refinement, physical transfer and
  action compilers are genuine closed dependencies, but their conditional
  spectral reduction theorem is not thm:fixed or thm:family.
  The following remaining nodes must have callers in the actual algorithm:
    verified fast tensor-symmetric matrix kernels;
    fast random embeddings with quantified simultaneous Loewner events;
    support reduction, deficient/zero-support branches and exact bases;
    base Newton/Cholesky invariant and its finite costs;
    fine mass/action instantiation and recursive factor action bounds;
    near-threshold generalized min-max and ordered mass comparison;
    coefficient-ratio initialization and exact shifted inertia;
    actual Krylov per-vector approximation theorem and repetition bounds;
    safe below/above/near decisions and positive bisection bracket/cap;
    Gaussian covariance-conditioned final strong capture and carried lift;
    adaptive conditional probability budget, all-outcome caps and outputs;
    fixed-depth total work; schedule/depth/uniform-log unfolding;
    all corollary algorithms and comparator algorithms.

Threshold-track implementation contract

  MinMax*.lean will define an explicitly sorted eigenvalue using Mathlib's
  LinearMap.IsSymmetric.eigenvalues, not Matrix.eigenvalues whose index
  permutation is unspecified. Prove the dimension/variational bridge,
  then Loewner and generalized-mass eigenvalue comparisons.
  MassSpectrum*.lean will connect actual masses and congruences to the
  ordered generalized eigenvalues and squared product singular values.
  Threshold*.lean will implement safe decision logic, bracket refinement
  and its halving/query cap; its Gaussian Krylov and exact-inertia inputs
  are intermediate interfaces until actual verified implementations call it.

Never declare the full theorem using existence of a successful sketch,
filter, threshold certificate, or same-cost algorithm as a hypothesis.
Never name a conditional reduction as the main theorem. A final main
signature may use only the manuscript's inputs and original feasible-kernel
model witnesses; all other mathematical and algorithmic nodes must be built.

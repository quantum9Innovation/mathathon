Fix a>=0,b>=1,D=a+b>=3 and the actual independent uniform-simple
internal/random-bipartite-cross model on two N-vertex planted blocks.
All limits range through EVERY admissible N. Let K count valid unordered
equitable (a,b) bisections. Then

 Pr(K>=2)~C N^(-nu),
 Pr(K>=3)=O(N^(-nu-1)),
 uniform-hidden-prior Bayes error~(C/2)N^(-nu).

If a-b=delta>=0, set t=delta+1. Then

 nu=(D-2)t,
 C=((bt)!)^2(a!)^(2t)/[(t!)^2(b!)^(2t)a^(t delta)].

If a<b, set s=b-a. Then

 nu=(D-2)s,
 C=((as)!)^2(b!)^(2s)/[(s!)^2(a!)^(2s)b^(s^2)].

The second formula applies directly at a=0 with 0!=1. The first formula
at a=b>=2 gives t=1, C=(a!)^2, nu=2a-2. Other checks are (1,2): C=2,
nu=1; (1,3): C=16,nu=4; (0,b): C=(b!)^(2b-2)/b^(b^2),nu=b(b-2).
These are block-size-N constants. A deterministic polynomial worst-case
estimator attains the same leading Bayes coefficient.

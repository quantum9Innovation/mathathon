Candidate general-frame recovery by coarse modular entropy
=========================================================
Root proposal, November15. NOT AN AUDITED THEOREM YET.

Actual graph model: fixed k>=2, connected degree frame Q, internal degrees
a_i=d_ii>=2. Independent uniform internal regular factors and independent
UNIFORM biregular cross factors. Equal block sizes, or fixed rational size
ratios satisfying Ni*dij=Nj*dji. All admissible N; no even restriction.
Random cross factors are essential to the current type-counting argument.

Unknown candidate quotient R may have r<=K classes and bounded degrees D.
A one-hot label matrix Y (row in {e1,...,er}) is equitable exactly when
 A Y=Y R.
Over any fixed Fp, encode each root label as a vector in Fp^r. This is one
linear system with rn scalar variables. Its typed star constraint still
determines one internal-neighbor vector from root and other neighbors.
The fixed-alphabet exact configuration type count has entropy exponent
 Phi=sum_i Ni H(star_i)
       -sum_i Ni*ai/2 H(internalpair_i)
       -sum_(i<j) Ni*dij H(crosspair_ij).
Symmetrization and conditional subadditivity give
 Phi<=-sum_i Ni*(ai/2-1) I(internalpair_i)
       -sum_(i<j) Ni*dij I(crosspair_ij)<=0.
Thus E[number of Fp solutions to AY=YR]<=N^C(Q,R,p) by polynomially
many types and uniform Stirling bounds. This suggests expected polynomial
enumeration of all modular intertwiners, retaining verified one-hot rows.

Real partition rigidity: apply the SAME entropy count to real one-hot
labels with the INTEGER vector equation AY=YR. At Phi0, all cross
mutual informations vanish, and retained neighbors are conditionally
independent given the root. The conditional-variance proof from
rsbm-general-coarse-recovery-root.txt works with squared Euclidean norm:
 under P, trace conditional variance of omitted internal vector is v_i;
 under conditional-product R, its variance is
       (ai-1)v_i+sum_j dij Var(rootlaw_j).
For ai>=2 this forces every neighboring root law to have zero variance.
Connectedness of the old frame forces ALL root laws point masses.
Thus any zero-entropy candidate partition is constant on planted blocks,
equivalently is a coarsening of the planted partition.

Macroscopic alternatives: compactness gives a strict negative exponent
away from the finitely many point maps T:old blocks->candidate labels.
Pinsker yields quantitative versions if needed, using a fixed bound on R.

Near a point map T: let J be the planted indicator matrix and let S be
vertices where Y differs from JT. If QT!=TR, sufficiently small S leaves
in each planted block a vertex with itself and all neighbors unchanged;
its exact degree equation contradicts QT!=TR. Therefore QT=TR for every
feasible sufficiently near point map. Then V=Y-JT satisfies AV=VR and
has small row support S. At a vertex outside S, sum of neighboring rows
of V is zero, so it cannot have exactly one neighbor in S. The standard
unique-neighbor exposure estimate at minimum total degree>=3 rules out
all such small supports with high probability. This argument is vector
valued and does not require a scalar eigenvalue.

Unknown frame and k: enumerate the finite collection of nonnegative
integer candidate frames R with r<=K and row sums<=D. Restrict to
connected quotient frames and nonempty classes. Edge balance then gives
class sizes at least n/[K*D^(K-1)], so no vanishing tiny class escapes the
compactness step. The actual planted frame is among candidates. If the
rigidity argument above is valid uniformly over this finite collection,
all accepted partitions are coarsenings; selecting the largest number of
classes recovers the true k and partition, without knowing Q.

Important outstanding checks: exact vector-alphabet type count, weighted
entropy factors for unequal sizes, behavior under symmetrization, precise
constant-map neighborhoods, deterministic compatibility QT=TR, expected
enumeration cost and truncation, connected-candidate size bound, and
historical priority (Karmakar--Podder2002.05577 and later frame models).
This would substantially generalize the two-community coarse proof; it
must be independently audited before inclusion in a headline theorem.

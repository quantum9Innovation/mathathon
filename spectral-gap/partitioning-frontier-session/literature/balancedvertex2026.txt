                                         1    Introduction
                                         Partitioning a graph into smaller pieces is a fundamental problem that arises in many fields. One
                                         kind of graph partition with widespread applications in algorithms is the vertex separator: A
                                         small set of vertices whose removal disconnects the graph into small components.
                                            More generally, let G = (V, E) be a graph with n = |V | vertices, let w : V ∪ E → Z≥0 assign
                                         a polynomially-bounded P  weight to each vertex and edge, and let c ∈ (0, 1/2) be a constant. For
                                         Z ⊆ V ∪E, write w(Z) = z∈Z w(z). We treat vertex and edge separators in a common framework.
                                         A c-balanced element cut is a partition V = A ⊔ B ⊔ C with max{|A|, |B|} ≤ (1 − c)n, of cost

                                                                         cost(A, B, C) = w(C) + w(E(A, B)).

                                         It deletes the vertices in C and the edges between A and B. We also use w(z) = ∞ as notation
                                         for forbidding deletion of an element z. Vertex separators are the specialization w(e) = ∞ for all
                                         e ∈ E, and edge cuts are the specialization w(x) = ∞ for all x ∈ V . Write OPTc for the minimum
                                         finite cost of a c-balanced element cut, wmax for the maximum finite element cost, and W for the
                                         sum of all finite element costs. Balance always counts original vertices. For fixed sets to separate,

by an undeletable edge, and regard the original vertices as deletable nonterminals. Thus paths
pay for their original endpoints as well as their internal vertices.
    Small vertex separators are known to exist for many classes of graphs with uniform weights
                                                                                             √
w(·) = 1. Planar graphs are known to admit 13 -balanced vertex separators of size O( n) [43,
                                                                                      √
33], genus-g graphs are known to admit 31 -balanced vertex separators of size O( gn) [21], and
similar results are known for minor-free graphs [22], geometric graphs [37, 42], induced-minor-free
graphs [25], and other classes [36, 12]. These small separators also have numerous applications. To
name a few, they naturally allow devising divide and conquer algorithms, dynamic programming
algorithms, subexponential algorithms for NP-hard problems on special graphs, and maximum
matching algorithms [39, 34, 25].
    Unfortunately, while optimal planar separators can be found in linear time, none of these other
results correspond to particularly fast algorithms often requiring exponential time in a parameter.
For genus-g graphs, the best-known separator theorem requires a surface-map/rotation system [21],
which takes time exponential in g to compute [38, 6], meaning it cannot be used to compute separa-
tors for graphs with even a small genus of polylog(n) in polynomial time. In the case of minor-free
graphs, the time complexity can be even worse: One of the best-known separator theorems [22] cor-
responds to an algorithm which uses time proportional to multiple tower functions in the size of the
minor. At best, some of the constructions correspond to polynomial-time algorithms (with a large
polynomial overhead), such as those of induced-minor-free graphs [25], but such results are typically
conjectured to be significantly sub-optimal existential bounds for the classes to begin with. Due
to the significant overhead of these algorithms, many direct applications of recursively-separable
graphs assume some routine is provided that produces a separator, and the time complexity of the
assumed routine is incorporated into their final result [15, 26, 2, 16, 23, 17, 10, 32, 44].
    Even for cases where the graph class might admit a fast algorithm (such as planar graphs),
such algorithms only apply to graphs within their respective classes. In most practical settings for
graph partitioning, we do not have any special guarantees that the graph falls into a certain class,
but a graph might still have a small separator without properly falling into a special class: For
instance, road networks, which are known to admit empirically good separators [14], are almost
planar, in the sense that removing a relatively small number of vertices corresponding to structures
like bridges will make them planar. Or, more theoretically, a graph could be nearly minor-free, in
the sense that it contains a very large minor-free induced subgraph.
    Thus, we naturally turn to the question of approximation algorithms: Given a graph G, can
we approximate the minimum c-balanced vertex separator? It turns out that this is essentially
impossible as-stated: It is NP-hard to approximate the minimum c-balanced vertex separator up
                                         1
to an additive approximation of O(n 2 −ϵ ) for any ϵ > 0 [7]. Fortunately, we may instead use
pseudo-approximations (also called bi-criteria approximations): For a graph G whose minimum
c-balanced vertex separator has size OPTc , we can produce a Θ(c)-balanced vertex separator with
size close to OPTc .

     Approximation algorithms for balanced vertex separators have a long history. First, it should
be noted that there is a standard reduction from the balanced vertex separator problem to the
(weighted) balanced directed edge separator problem based on vertex-splitting, preserving approx-
imation ratios up to constants. For papers that study balanced directed edge separators directly,
we will only discuss their implications for vertex separators.
     Polynomial-time O(log n)-approximations date back to√       Leighton and Rao in 1988 [30, 31], and
the best-known polynomial-time approximation ratio is O( log n), achieved independently by two
groups at STOC 2005 [18, 1]. However, all of these algorithms are quite slow. The first requires
up to O(n) solves of linear programs with a large number of constraints, while the latter two
require up to O(n) solves of large semidefinite programs with a large number of constraints. The
number of solves is because each problem is solving the related problem of minimum-ratio vertex
cut: Roughly speaking, this refers to finding a set of vertices S whose removal disconnects a small
component C of the graph, while minimizing |S|/|C|.
     Progress on fast approximation algorithms with polylogarithmic approximation ratios has been
much slower, and often involves unusual tradeoffs. In 2007, Arora and Kale presented an O(log n)-
approximation using O(1)  e     strongly-polynomial maximum flow computations [3], and hence runs
in e     1.5
    O(m ) time for a graph with m edges. It should be noted that their algorithm does very much
require strongly-polynomial maximum-flow, and does not admit an immediate replacement: The
bit-complexity of the inputs to their flow problem is polylogarithmic only if they are represented
with floating point arithmetic. This prevents an immediate application of almost-linear time
maximum flow [9], which applies for integer inputs of polynomial magnitude. That said, we think
it is feasible that a slightly-modified form of their algorithm could be made to appropriately√handle
bit-complexity. This would require more work. Arora and Kale also presented an O( log n)-
approximation running in O(n   e 2 + m1.5 ) time using multicommodity flow.
     Since then, there have been a number of alternative results. In 2010, Louis [35] posted a preprint
claiming to attain a polylogarithmic approximation in a polylogarithmic number of maximum flow
computations using a “cut-matching game”. Unfortunately, the details of this proof were never
published. However, if the suggested algorithm does work, it does at least appear that it would
not require any extra care for handling bit-complexity.

1.3   Technical Overview
The overall structure of our algorithm is closest to the methods of Arora and Kale and follow-up
works [3, 40, 24] for the balanced (edge) separator problem. Accordingly, we first give a brief
overview of the latter problem, and discuss the precise point at which the same approach fails,
requiring new ideas. Our method also bears some similarities to a slightly different approach of
Lau, Tung, and Wang [28] for the directed edge expansion problem, and we discuss where this
approach fails as well. Both of these previous works, as well as ours, make use of the “Matrix
Multiplicative Weights Update” algorithm (MMWU), which is an online learning algorithm for
the so-called “Matrix game” [3, Algorithm 1]. However, their implementations of this algorithm
differ significantly.
Balanced edge separator First, the methods of Arora and Kale define an SDP relaxation of the
problem that involves vector-valued variables vi ∈ Rn for each node i ∈ V . This relaxation is then
approximately solved using a primal-dual Matrix Multiplicative Weights Update framework [3,
Algorithm 2] (called the “Primal-Dual Algorithm for SDPs” in the cited version of their work),
which internally runs the MMWU algorithm while maintaining the variables vi explicitly. The
main subroutine of the primal-dual MMWU framework is a procedure called Oracle that does
the following: given the current primal solution (i.e. vectors vi ), it either finds a balanced separator
of small cost, or finds an inequality violated by this solution (specified by dual variables). This
inequality is then used to update vectors vi . This pair of valid outputs is key to keeping the
“width” low, which in turn allows for a fast time complexity.
    Different implementations of the oracle are presented in [3], [40] and in [24]. In particular, the
oracle in [24] works by running a sequence of maximum flow computations, extracting directed
matchings from these computations (via flow decompositions), and then “chaining” together these
matchings.
Sparse directed edge cuts Lau, Tung, and Wang take an alternative approach to integrating
the MMWU algorithm into their problem. There is a natural SDP relaxation of their problem
as well, but it would naturally involve both a vector-valued variable vi ∈ Rn and a separate real-
valued variable ri ∈ R for each node i ∈ V , with surprisingly challenging inequalities relating these
two (see also [27] for related SDPs with similar structure). The standard primal-dual MMWU
framework has no way to handle this structure, so Lau, Tung, and Wang instead use a min-max
form of their problem, with outer vector-valued variables vi ∈ Rn . In their case, the constraints on
the vector-valued variables in this min-max form happen to coincide with precisely the guarantees
that are maintained by the MMWU algorithm at all times. They then construct another Oracle
procedure that either solves the inner problem in a way that has low “width”, or outputs a
combinatorial solution.
    Importantly, their approach to analysis is rather ad-hoc, and only seems applicable to their
specific problem, while making constraints like balance much more difficult to handle nicely.
    On the technical level, our work introduces two new ideas, which are described below.
Technical contibution #1: partial variable MMWU framework For simplicity, let us
consider vertex separators. We start by defining an SDP relaxation of the problem which is a
variant of the SDP for the balanced edge separator (and distinct from previous SDP relaxations
for balanced vertex separators such as the SDP of Feige–Hajiaghayi–Lee [18]). Besides variables

                                                   5
vi ∈ Rn , we use scalar variables xi ≥ 0 that indicate whether node i belongs to the separator.
     One could now try to apply the primal-dual MMWU framework described above: maintain
primal variables vi , xi , find an inequality violated by these variables, and update these variables.
Unfortunately, we were unable to find such a scheme. Variables vi and xi play very different roles,
and it is not clear how to jointly update them while having a small “width” of the oracle. We also
tried to find a usable min-max formulation, but, as mentioned, the balance requirement prevents
the same trick of [28] from being applied to our problem, since the MMWU algorithm does not
automatically satisfy these constraints.
     Overcoming this difficulty was the first technical challenge that we faced. To resolve it, we
avoid the standard primal-dual MMWU framework, and instead use a hybrid of the two approaches
(which we will call the “partial-variable” MMWU framework): we maintain and update variables
vi , but not xi . The latter are maintained neither explicitly nor implicitly, even though they are
part of the primal SDP formulation. We carefully design an oracle that does not need variables
xi as input, while still outputting dual variables, and we apply the MMWU regret-minimization
bound directly to the output of this oracle. We also extend this framework to a more general class
of SDPs.
Technical contribution #2: new oracle for the padding bound To prove Theorems 1
and 5, we provide two different implementations of the oracle. The oracle for the first theorem
is very close to the one in [24]; the main difference is that we generalize the minimum s-t cut
subroutine for edge separator to element separators. For Theorem 5 we use a very different
approach. First, we use random sampling to construct an instance of a multicommodity flow
problem, which we then approximately solve using the algorithm in [8]. If the flow is large then its
demand graph gives a valid output of the oracle (a feedback matrix of small width). The case of
small flow is the most technically challenging part of the analysis. First, we use dual prices of the
multicommodity flow problem to construct a shortest path pseudometric on V . We then apply the
definition of the padding bound and show the existence of Lipschitz approximation to Gaussian
projections. Using this approximation, we finally prove that an s-t minimum cut computation for
a random Gaussian direction yields a balanced element cut of small cost with constant probability.

1.3.1   Bit complexity
Like previous works [3, 28], we apply maximum flow as an important subroutine. Moreover, de-
pending on the value of the maximum flow, we may need to produce a corresponding minimum
cut. For both vertex capacitated and directed graphs, the fastest-known maximum flow algorithm
(exact, approximate, or otherwise) is the recent almost-linear time exact maximum flow result of
Chen et al. [9], which only applies to networks with bounded integral capacities. This presents an
issue for prior work: As presented, both the work of Arora and Kale for balanced edge separator [3]
and its follow-up works [40, 24], as well as the work of Lau, Tung, and Wang [28] present their algo-
rithms for real-valued weights. Since almost-linear time maximum flow requires bounded integers,
a bit more work would be required to complete the analysis in these works in this paradigm.
    In the case of balanced edge separator, there are alternative strongly near-linear-time undi-
rected maximum flow routines that may be used instead [20]. However, in the case of directed
edge expansion, there is no such alternative.
    For our problem, we use the element-capacitated network to devise our maximum flow instances
in such a manner that their capacities do not depend on the maintained variables {vi } in any way.
However, while this is the main step required to avoid such issues, this does not automatically
handle our bit complexity bounds, since our capacities do still depend on a number of different
quantities, including our finite element costs, a guess at the value of the optimum solution (obtained
via binary search), and several constants. To handle this cleanly, we parametrize some of our
maximum flow instance capacities with a parameter µ, and prove several intermediate results for


                                                  6
a value of µ falling into a wide range. Then, our final proofs pick an appropriate value of µ that
falls into that range while having small bit-complexity.

3      A new matrix multiplicative weights method
As previously discussed, we are unable to apply the general primal-dual framework of Arora
and Kale [3]. However, we still leverage some of the same high-level steps. Instead of solving

We will reduce the problem to a maximum multicommodity flow problem in a directed weighted
graph G and then apply the algorithm of Chen-Graur-Sidford [8] for the latter problem. Start with
the network N (∅, ∅, µ) of Section 5, remove s, t, and add:

   • for each x ∈ S, nodes x⊖ , x⊕ , an arc (x⊖ , x⊕ ) of capacity µ, and infinite-capacity arcs
     (x⊕ , x+ ) and (x− , x⊖ );

   • for each rectangle Qi = Ai × Bi , private nodes si , ti and infinite-capacity arcs (si , x⊖ ) for
     x ∈ Ai and (y ⊕ , ti ) for y ∈ Bi .

Note that G has M = O(mq) nodes and edges.
    Now consider the maximum multicommodity flow problem in G with q terminal pairs {(si , ti )}qi=1 .
We claim that it is equivalent to the maximum µ-uniform Q-flow problem, i.e. there are value-
preserving transformations between the problems in each direction. Indeed, use the path lifting
and projection from Lemma 12(b) for the vertex and edge gadgets. For a path with endpoints
a ∈ Ai , b ∈ Bi , prepend (si , a⊖ , a⊕ ) and append (b⊖ , b⊕ , ti ). The gadget arcs enforce exactly the
vertex and edge loads, and each endpoint gate is used once per incident demand, enforcing the
shared bound µ across all rectangles and both endpoint roles. Conversely, remove flow cycles and
project each simple si -ti path. Such a path cannot traverse an endpoint gate internally, since
it would revisit the corresponding split vertex; private sources and sinks cannot occur internally
                                                  paths
either. The resulting paths therefore lie in Qi         and satisfy all three load constraints with the
same total value.
    Next, we apply the algorithm in [8] for the approximate multicommodity flow problem. It
produces a flow of value at least (1 − ε′ ) of the optimum in O(M 1+o(1) q/ε′ ) time, assuming that
weights are polynomially-bounded integers. (In our case edges with infinite weights can be safely
replaced with M cmax + 1 where cmax is the maximum finite weight in G). Cycle removal and
endpoint decomposition take O(M log(n+q)) time per commodity using dynamic trees [41, Section
6] and pseudo-decomposition [40, Lemma 3.7]. Recording only the endpoint pairs and their weights
constructs the demand graph Dν with O(M q) edges in total, without listing path interiors.
    We arrive at the following result.

Theorem 17. For a given value µ = a/b with polynomially-bounded integers a, b we can in
m1+o(1) q 2+o(1) time compute a µ-uniform Q-flow ν, represented implicitly, of value at least OPTQ /2,
and construct the demand graph Dν with O(mq 2 ) edges.

Remark 1. Alternatively, an approximate µ-uniform Q-flow with desired guarantees could be
computed via calls to a minimum-cost flow subroutine using the MWU frawework; this was the
solution originally proposed by AI. We replaced it with a reduction to the algorithm in [8], which

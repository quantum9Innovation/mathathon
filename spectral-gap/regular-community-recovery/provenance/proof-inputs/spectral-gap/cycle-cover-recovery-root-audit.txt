1. The hiding experiment and constant joint likelihood
------------------------------------------------------
There are k named base vertices and n=kN observed vertex labels. Start
with independent uniform perfect matchings on the k base edges, then
globally relabel all n vertices uniformly. Its equivalent description
is a uniform balanced named map f:[n]->Z/kZ followed by independent
uniform matchings between consecutive named fibers.

The number of balanced named maps is n!/(N!)^k. Conditional on f,
there are (N!)^k matching choices. For a compatible observed SIMPLE
graph G, each base-edge matching is uniquely determined by G and f.
Hence

  P(f)=(N!)^k/n!,        P(G|f)=(N!)^(-k),
  P(f,G)=1/n!.                                           (A1)

This accounts for the globally hidden fiber prior exactly. A uniform
global relabeling makes f uniform; residual independent permutations
of the within-fiber names preserve the matching laws. No graph-
automorphism divisor is inserted into (A1), because G is observed
on its fixed labeled vertex set.

For k>=4, a fixed UNORDERED partition has k! named labelings but only
2k can be compatible with any particular G and the given named cycle.
The source correctly works with named maps first rather than assuming
every cyclic order of the blocks has the same compatibility event.


2. Monodromy, all component sizes, and the small base cases
----------------------------------------------------------
Gauge the matchings on a spanning path of C_k to identity by transporting
sheet names. The remaining matching is a uniform permutation pi in S_N.
An orbit of length ell yields one component cycle of length k ell.
Thus the number R(G) of components has exactly the uniform permutation
cycle-count law, for every N. Changing the orientation convention only
inverts/reorders uniform permutations and does not change that law.

The base is SIMPLE and k>=3, so every lifted component is a simple
cycle and its two neighbors are distinct vertices. The source correctly
excludes k=1,2; using a two-edge multigraph as C_2 would be a different
covering model with different local statements.


3. Exactly 2k maps on a fixed labeled component
------------------------------------------------
Fix a vertex and an orientation of a component cycle of length k ell.
A covering map to C_k chooses its first image a in k ways and its
direction in two ways. Local bijectivity forces every successive step
to keep the same direction: reversing would send the two distinct
neighbors of a vertex to the same base neighbor. Thus every map is

  j -> a+j mod k    or    j -> a-j mod k.

All 2k are distinct for k>=3, including k=3. Every component gives
ell vertices to every base fiber; consequently any choices on different
components automatically satisfy the global fiber balance N.

There is no additional ell factor from changing the component start:
the observed start vertex was fixed, and rotation by k steps leaves
the SAME map as a function on the labeled vertices. Deck coordinates
within a fiber are not part of the recovery target.


4. One global Aut(C_k) quotient, not one per component
------------------------------------------------------
On a graph with R components, named covering maps number (2k)^R.
Two such maps f,g have the same unordered partition if and only if
g=sigma composed with f for one permutation sigma of all k base names.
Surjectivity makes sigma unique. Since every base edge is covered and
g is also a covering map, sigma sends every cycle edge to a cycle edge.
It is therefore a graph automorphism of C_k.

Conversely every global base automorphism preserves the unordered
partition. Aut(C_k) has k rotations and k reflections, so order 2k.
Its action on covering maps is free because a surjective map cannot
be fixed by a nonidentity base permutation. Therefore

  M(G)=(2k)^R/(2k)=(2k)^(R-1).                            (A2)

Relative phases and directions on different components change the
partition on the actual vertex set. They are not independently
quotiented out. Repeated component lengths also do not permit an
extra quotient: swapping two observed components permutes labeled
vertices and can change the target partition.

By (A1), each compatible unordered partition accounts for exactly
2k compatible named maps and has joint probability 2k/n! with G.
Thus its posterior is uniform on the M(G) possibilities. Marginally,

  P(G)=(2k)^R/n!.                                        (A3)

The largest posterior mass is M(G)^(-1), attained by any compatible
partition. Thus optimal conditional Bayes success is (2k)^(1-R).


5. Two independent derivations of the exact average
---------------------------------------------------
First use the permutation component law. Insert the Nth element into
a permutation of N-1 elements. As a singleton it creates one new cycle;
in the other N-1 insertions it preserves the cycle count. Consequently

  E t^(R_N)=t(t+1)...(t+N-1)/N!
           =Gamma(N+t)/[Gamma(t)Gamma(N+1)].

Take t=1/(2k) and multiply by 2k. This proves the source formula.
The fixed-t Stirling ratio is Gamma(N+t)/Gamma(N+1)~N^(t-1), giving
the exact exponent and constant claimed. One must average the cycle
count generating function, not substitute its typical value.

As an independent global likelihood and normalization check, suppose
a graph has m_ell components of length k ell. The number of distinct
labeled graphs with this cycle inventory is

  n! / product_ell[(2k ell)^(m_ell) m_ell!].

This comes from the (L-1)!/2 distinct undirected cycles on a fixed
L-vertex set and unordered selection of components. Multiplying
by (A3) cancels the 2k factors and gives inventory probability
product_ell[ell^(-m_ell)/m_ell!], exactly the permutation inventory
law on N sheets. Summing it normalizes to one since

  exp(sum_(ell>=1) x^ell/ell)=(1-x)^(-1).

Furthermore, optimal Bayes success is sum_G max_Pi P(G,Pi).
By (A1)--(A2) that maximum equals 2k/n! for every support graph.
The labeled-graph count generating function is

  exp(sum_(ell>=1) x^ell/(2k ell))=(1-x)^(-1/(2k)).

Its coefficient gives the SAME optimal success
2k (1/(2k))_N/N!, where the subscript denotes the rising factorial.
This second derivation independently checks the global quotient,
repeated-component factors, marginal normalization, and gamma formula.

The stated finite cases also agree directly:
  N=1: success 1;
  N=2: success (1+1/(2k))/2, giving 7/12 at k=3 and 9/16 at k=4;
  k=3,N=3: cycle probabilities 1/3,1/2,1/6 at R=1,2,3 give
             1/3+1/12+1/216=91/216.


6. Randomized minimax equality and what it does NOT assert
----------------------------------------------------------
Let f range over all balanced named projections, with observation law
given by independent edge matchings. Worst-case success of any estimator
cannot exceed its uniform-prior average, and the maximum average is
the Bayes value above. This gives the minimax upper bound.

For the converse, sample uniformly from the M(G) compatible unordered
partitions. For every G and every compatible true parameter f, the
estimator's own randomization gives success exactly 1/M(G). For each
fixed f the monodromy is uniform and has the same R_N law. Therefore
the averaged success equals the Bayes value for EVERY f, proving the
randomized minimax equality. This is an explicit equalizer estimator;
no abstract minimax theorem or unjustified prior invariance is needed.

The source's uniform sampler is correct. Choose canonical observed
starts and orientations of components, and fix one component's map.
The global automorphism group acts freely and transitively on that
component's 2k possibilities. Each unordered-partition orbit therefore
has exactly one representative satisfying this gauge. Independently
choosing each remaining component's 2k maps uniformly selects every
unordered partition exactly once. This is easily implemented by cycle
traversal; computational limits are irrelevant to the obstruction.

The upper bound is NOT a bound on every estimator at one specially
chosen fixed f: an estimator can hardcode its unordered partition.
Nor is the source claiming deterministic minimax equality without
randomization. Its stated prior/global-shuffle and randomized minimax
qualifications are correct and necessary.


7. Connected conditioning and known k
--------------------------------------
A uniform permutation of N sheets has one cycle for exactly (N-1)!
of its N! outcomes. Thus the unconditioned lift is connected with
probability 1/N. At R=1, (A2) gives exactly one compatible unordered
partition. Given k, traverse the observed cycle and group vertices
by position modulo k; rotations and reflection only rename those
same cells. This recovers the target with probability one under
connected conditioning.

This does not contradict the unconditioned success tending to zero.
It also does not identify an UNKNOWN base size: a cycle can cover
other simple cycles whose orders divide its length, and those give
different fiber partitions. The source explicitly retains the known
base and excludes that different identification problem.


8. Assessment and limitations
------------------------------
No required correction was found in the actual five-page source.
The exact posterior support and success exponent are supported by
both independent counts above. The degree-two obstruction applies
to blind, globally hidden, UNCONDITIONED random lifts of a fixed
known simple cycle; the connected submodel has the different behavior
stated in the source. The target is the unordered vertex partition,
not hidden names, a base orientation, or sheet coordinates.

The result supplies an information-theoretic boundary for comparison
with the separately proved d>=3 random-lift recovery theorem. It
does not cover growing base size, noisy observations, arbitrary
deterministic lifts, other priors, or unknown base sizes. Historical
priority is not certified by this proof audit.

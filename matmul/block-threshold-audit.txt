Stronger spectral certificates: removing the greedy sqrt(r) loss
Independent mathematical audit, 2026-11-14

STATUS

The sqrt(r) loss CAN be removed from the input-iteration term by going
beyond relative leading-Rayleigh accuracy. A low-eigenspace leakage
certificate (cPCA) suffices. Sections 1--4 below prove the required
Nystrom reduction and a self-contained positive-shift, fixed-polynomial
cPCA implementation. Section 5 records an alternative implementation via
the primary AppxPCA theorem, suitable for substituting faster stochastic
linear solvers. It includes a computable near-isotropic start and no
singular-value-ratio dependence.

For the existing deterministic preconditioned solver, the proved general
rank bound becomes

  ~O(I+G_h+m^(omega+zeta)+r*m^2/sqrt(h)
       +I*r*sqrt(h/theta)+m^2*r^(w-1)+T_MM(n,r,p)),          (A)

where 9/4<w<min(5/2,9/4+zeta) is a feasible square exponent. The
shared-core preparation term m^2*r^(w-1) must now remain explicit;
the old sqrt(r) input term can no longer automatically absorb it.
It is absorbed whenever

  (I/m^2)*sqrt(h/theta) >= m^(w-2),

which covers the current high-accuracy output regimes uniformly for r<=m.

The more global absolute-pencil idea from the task also has a useful
proved quadratic block certificate, in Section 6. It is not by itself
a complete global rank-threshold selection algorithm. The cPCA reduction
already provides a complete way around greedy precision accumulation.

All claims are exact real-arithmetic claims in the manuscript's model.
No global novelty or stable finite-precision theorem is asserted.


1. A TAIL-MASS NYSTROM LEMMA

Let H>=0 have descending eigenvalues lambda_1,...,lambda_d. Let z be
unit, s=z^T H z>0, and R=H-Hz z^T H/s. For 1<=j<d write

  t=lambda_{j+1}(H),
  w_j=||Pi_{bottom d-j eigenvectors} z||^2.

If w_j<1, then

  lambda_j(R)
    <= lambda_1*t/[lambda_1*(1-w_j)+t*w_j]
    <= t/(1-w_j).                                        (1)

In particular, bottom-tail mass <=epsilon implies
lambda_j(R)<=lambda_{j+1}(H)/(1-epsilon).

Proof.
First take a simple positive spectrum and nonzero coordinates of z in
the eigenbasis. If t=0 the result follows by rank drop, so consider t>0.
The nonzero residual roots interlace H's eigenvalues and obey

  f(mu)=sum_i lambda_i*z_i^2/(lambda_i-mu)=0.

This follows from the rank-one determinant identity, using
lambda_i^2/(lambda_i-mu)=lambda_i+mu*lambda_i/(lambda_i-mu).
The function is increasing between adjacent poles. Let

  mu0=lambda_1*t/[lambda_1*(1-w_j)+t*w_j].

If mu0>=lambda_j(H), interlacing proves the bound. Otherwise the
head terms are positive and, because x/(x-mu0) decreases for x>mu0,

  positive head >= lambda_1*(1-w_j)/(lambda_1-mu0).

The negative tail magnitude is at most t*w_j/(mu0-t). These two
expressions are equal at the displayed mu0. Thus f(mu0)>=0, and
the interlacing residual root is at most mu0. Continuity handles repeated
eigenvalues, zero coordinates, w_j=0, and semidefinite H. If the
corresponding tail eigenvalue is zero, rank(R)=rank(H)-1 supplies the
same conclusion. The formula is sharp in the two-dimensional case.

The statement is stronger than a relative-Rayleigh Nystrom bound: it
uses WHERE z's error lies, not merely its lost Rayleigh value.


2. A STRONG cPCA ORACLE IMPLIES GAP-FREE RANK-r SPECTRAL ERROR

For a nonzero PSD residual H_i, suppose an oracle returns a unit z_i
satisfying

  ||Pi_{lambda <= (1-gamma)lambda_1(H_i)} z_i||^2 <=epsilon. (2)

No gap at that cutoff is assumed. Define the usual right Nystrom update
of M_i by v_i=M_i^T z_i/sqrt(z_i^T H_i z_i). This produces

  H_{i+1}=H_i-H_i z_i z_i^T H_i/(z_i^T H_i z_i).

For r successful stages with fixed gamma,epsilon in (0,1),

  lambda_1(H_r)
    <= lambda_{r+1}(H_0)/[(1-gamma)(1-epsilon)^r].           (3)

Proof by a moving tail threshold.
Put t0=lambda_{r+1}(H_0), alpha=(1-epsilon)^(-1), and t_i=alpha^i t0.
Initially lambda_{r+1}(H_0)=t0. Inductively, as long as no earlier
case below has finished the analysis, maintain

  lambda_{r-i+1}(H_i)<=t_i.

If lambda_1(H_i)<=t_i/(1-gamma), all later residuals are PSD
downdates of H_i, hence their maximum eigenvalue is no larger. This
already proves (3). Otherwise t_i<(1-gamma)lambda_1(H_i).
The bottom eigenspace starting at index r-i+1 then lies inside the
bad eigenspace in (2). Apply (1) with j=r-i to obtain

  lambda_{r-i}(H_{i+1})<=t_i/(1-epsilon)=t_{i+1}.

At i=r the invariant gives the desired bound. The analysis need not
tell the algorithm when the first case occurred. If t0=0, exact rank
drop proves the result; if a residual becomes zero, stop immediately.

For 0<theta<1 choose

  gamma=theta/2,  epsilon=theta/(2r).

Bernoulli gives (1-epsilon)^r>=1-theta/2=1-gamma. Therefore

  ||M-MV_r V_r^T|| <= sigma_{r+1}(M)/(1-theta/2)
                   <= (1+theta)sigma_{r+1}(M).             (4)

The rank-r factor guarantee follows, with exact zero-tail recovery.
Only the leakage tolerance epsilon depends on r, and an inverse-based
cPCA oracle depends logarithmically on that tolerance. The spectral
cutoff width gamma remains Theta(theta), removing the old sqrt(r).
This is a black-box reduction from (2), not an assertion that ordinary
Rayleigh witnesses meet (2).


3. A SELF-CONTAINED SAFE-SHIFT cPCA ORACLE USING EXISTING PRIMITIVES

Fix one residual H=M_i M_i^T with lambda=lambda_1(H)>0. Keep the main
manuscript's support coordinates

  Z=AW, G=Z^T Z, Q'=L Q_i L^T, H=Z Q' Z^T,
  I/(1+h)<=G<=I/(1-h), 0<h<=1/16.

Let 0<gamma<=h/2 and 0<epsilon<=1/4. All norms and random starts
in coefficient space use the true G metric, which applies in O(I).
The conceptual isometry ZG^(-1/2) and square root G^(1/2) are used
only to analyze eigenvectors; they are not constructed.

3.1 Scale and a safe shift

Call the existing leading-Rayleigh primitive with parameter gamma/8.
Its actual squared quotient s obeys

  (1-gamma/64)lambda<=s<=lambda.

Put delta0=gamma/64, and choose a shift t anywhere in

  [s/(1-4delta0), s/(1-5delta0)].                           (5)

If using the shared Frobenius inverse, choose a nonpole in this interval
by the same a+1-point companion-polynomial test. No eigenvalue oracle is
needed. Direct scalar estimates give

  (gamma/32)lambda <= t-lambda <= (gamma/8)lambda.           (6)

The true stiffness K=tG-GQ'G is SPD. The explicit current-core proxy
F=(1+32h)tI-Q0 has

  22htI<=F-K<=42htI.

These comparisons remain valid above lambda even if t is outside the
old initial bracket: ||Q'||<=(1+h)lambda<=2t and
||Q0||<=(1+h)^2lambda<=(1+3h)t suffice for their proofs.

Also K>=(t-lambda)G>=(gamma/40)tI. Consequently the preconditioned
operator A=F^(-1)K, selfadjoint in F, has spectrum in

  [gamma/(4096h),1].                                     (7)

For instance F<=K+42htI<=(1+1680h/gamma)K gives the stronger lower
bound gamma/(1681h). Constants in (7) are deliberately loose.

3.2 A FIXED symmetric approximate inverse

Apply the manuscript's explicit Legendre inverse-root polynomial p to
A on the interval (7), at relative tolerance nu. It has degree

  ~O(sqrt(h/gamma)*log(1/nu))

and is evaluated with arithmetic, division, and scalar square roots
only. A's action uses true K and the exact shared F inverse. Define

  S_hat=p(A)^2 F^(-1).

This is a symmetric positive matrix. In analytical symmetric coordinates
C=F^(-1/2)KF^(-1/2), it equals

  S_hat=F^(-1/2)p(C)^2 F^(-1/2),

so

  (1-nu)^2 K^(-1)<=S_hat<=(1+nu)^2 K^(-1).                (8)

There is no adaptively stopped nonlinear solve inside a power iteration.
The polynomial and its degree are fixed at this stage.

3.3 An explicit power/precision argument, with no singular-value ratio

Let c=gamma*s/64 and let B=c K^(-1)G, selfadjoint in G. Its eigenvalues
are c/(t-lambda_j(H)). By (6), its largest eigenvalue b1 satisfies

  1/10<=b1<=1/2.

Every eigenvalue corresponding to lambda_j<=(1-gamma)lambda is at
most b1/9. All dependence on spectral scale has disappeared.

Take a fresh standard Gaussian in coefficient space and G-normalize it.
With failure probability beta', its conceptual symmetric-coordinate
squared overlap with one fixed top eigenvector is at least

  alpha0^2=(beta')^3/(16a),                               (9)

because kappa(G)<2. This is the Gaussian overlap/Markov argument in
docs/shared-threshold-audit.txt, with the mass G instead of a threshold
preconditioner. Allocate beta' separately from the initial Rayleigh call.

Choose an integer q by repeated multiplication so that

  9^(-q)<=alpha0*sqrt(epsilon)/16.

Then q=O(log(a/(beta'*epsilon))). For the exact B-power vector w,
its norm is at least alpha0*10^(-q), and its bad-eigenspace component
is at most sqrt(epsilon)/16 times its norm.

Use B_hat=c S_hat G, with

  nu=alpha0*sqrt(epsilon)*10^(-q)/(100q).

The symmetric-coordinate matrices obey
||B_hat-B||<=2nu and max(||B_hat||,||B||)<=1, by (8).
The telescoping power identity therefore gives

  ||B_hat^q-B^q||<=2q nu
      <=(sqrt(epsilon)/50)||w||.

After G-normalization, the computed vector has squared bad leakage
strictly below epsilon. Its physical lift z=Zx/sqrt(x^T Gx) therefore
satisfies (2). The same estimate proves it is nonzero.

Crucially log(1/nu)=O(log(a/(beta'*epsilon))) up to logarithms of
logarithms. The exponentially small value 10^(-q) causes NO polynomial
precision cost because q itself is logarithmic in the problem parameters.
No lambda_1/lambda_k or factor-condition ratio appears. Scalar coefficient
work and the outer power count are only polylogarithmic. The main true
action count is ~O(sqrt(h/gamma)), with O(I) work per action.

This gives a fully constructive cPCA oracle from the existing one-level
preconditioner, rather than merely naming a stronger black box.


4. GENERAL-RANK COST, ADAPTIVITY, AND EXACT ZERO TAILS

Reuse every initial embedding and the exact proxy updates from the
manuscript. Each new right vector lies in range(B^T); orthogonality and
the coefficient updates remain exactly the same as before. On the good
events, leakage (2) implies

  z_i^T H_i z_i>=(1-gamma)(1-epsilon)lambda_1(H_i)>0.

Thus the Nystrom step is defined, and every nonzero residual loses exactly
one rank. If rank(M)<=r, it becomes zero by that many steps, regardless
of how small the nonzero singular values are. The zero proxy test remains
valid. No limiting accuracy argument is used for exact recovery.

The initial leading-Rayleigh call in Section 3 has parameter Theta(gamma),
not epsilon. Its cost and all polynomial-inverse work are

  ~O(m^2/sqrt(h)+I sqrt(h/gamma)
                +m^2(1+i)^(w-2))

at stage i, after the common initial setup. The last term is the shared
core preparation from the exact Frobenius/Woodbury construction. Its
sum is m^2 r^(w-1), which MUST remain explicit now that the input term
is linear rather than r^(3/2). This establishes (A).

Condition on all previous outcomes and choose fresh Gaussian starts at
each call. Allocate the common embedding failure event and the O(r)
stage budgets within delta, with logarithmic per-call allocations as
usual. Everything inside each polynomial is fixed linear arithmetic.
The true-vector formation and dual lifting to final factors cost O(Ir),
already included. Explicit expansion costs T_MM(n,r,p).

The method has no gap assumption, no nonzero-tail promise, and no
leading-to-tail singular-value ratio in its arithmetic bound. Its proof
uses a stronger certificate than the sharp Rayleigh-only example permits.


5. APPxPCA WRAPPER FOR A FASTER POSITIVE-SHIFT SOLVER

The safe-shift initializer in Section 3 costs I sqrt(h/gamma). To use a
faster solver that would beat that term, replace the WHOLE cPCA stage,
including scale refinement, by the safe-shift search already proved by
Allen-Zhu--Li:

  LazySVD: Even Faster SVD Decomposition Yet Without Agonizing Pain,
  arXiv:1607.03463v2, Algorithm 1 and Theorem 3.1, PDF printed page 5,
  Appendix A.2 for shift safety.
  https://arxiv.org/pdf/1607.03463

The theorem returns squared leakage <=epsilon below
(1-gamma)lambda_1. It uses O(log(1/gamma)*m1+m2) approximate inverse
calls, where m1=O(log(a/p)) and m2=O(log(a/(p epsilon))). Every queried
shift alpha satisfies

  alpha/(alpha-lambda_1(normalized M)) <=12/gamma,
  1/(alpha-lambda_1(normalized M))
      <=12/[gamma*lambda_1(normalized M)].                 (10)

It does NOT first use I/sqrt(gamma) ordinary Lanczos. Its inverse-power
tests safely reduce the shift distance geometrically.

5.1 A scale available at input-plus-core cost

Use constant-distortion coarse Grams and the original cheap dense-core

  lambda_1(H)<=b0<=3lambda_1(H)/2.

This costs ~O(I+m^omega) initially; after adaptive deflation the coarse
proxy updates and another constant-accuracy dense-core norm estimate cost
~O(m^2)<=~O(I). If the residual coarse proxy is zero, stop exactly.
Normalize the CONCEPTUAL symmetric matrix

  S=G^(1/2)Q'G^(1/2),  M_norm=S/b0.

Its largest eigenvalue lies in [2/3,1]. Hence (10) has no dependence on
the unknown scale or a singular-value condition number.

5.2 Generalized inverse implementation and error metric

The coefficient operator similar to M_norm is Q'G/b0. A shifted inverse
call applied to a coefficient vector v is

  x=b0 K_s^(-1)Gv,
  K_s=sG-GQ'G,  s=alpha*b0.

Equivalently, solve the NORMALIZED SPD system

  (K_s/s)x=Gv/alpha.                                      (11)

By (10), mu=(s-lambda_1(H))/s>=gamma/12 for every queried system.
All raw shifts are O(lambda_1(H)). The full Gv and all power-method
norms, scalar inner products, and normalizations use O(I) exact work
per oracle call, only polylogarithmically many calls.

The Euclidean oracle error in conceptual symmetric coordinates is

  ||G^(1/2)(x-x_exact)||.

Since gmax=lambda_max(G)<=16/15, a coefficient Euclidean error at most
epsilon_oracle/sqrt(gmax) suffices. A normalized strongly convex quadratic
objective gap at most mu*epsilon_coeff^2/2 guarantees this error.
RHS norms may grow during unnormalized powers, but their logarithms are
O((m1+m2)log(1/gamma)), because all normalized inverse norms are O(1/gamma).

The literal paper displays absolute inverse accuracies

  epsilon_1=(gamma/6)^m1/(64m1),
  epsilon_2=epsilon*(gamma/6)^m2/(8m2),
  m1=ceil(4 log(288a/p^2)), m2=ceil(log(36a/(p^2 epsilon))).

Their log reciprocals are polylogarithmic in dimension, 1/gamma,
1/epsilon, and 1/p. In the generalized implementation it is harmless
and safer to choose stricter tolerances

  epsilon_1'=(gamma/C)^m1/(C m1),
  epsilon_2'=epsilon*(gamma/C)^m2/(C m2),

for a fixed C>=1000. They are below the displayed source tolerances
and cover the constant factors in the G-error metric and normalized
inverse-norm bounds. The deterministic inexact-power perturbation bound
uses only (C/gamma)^phase amplification, whose logarithm remains
polylogarithmic. There is no hidden sigma_1/sigma_{r+1} precision factor.

5.3 A computable near-uniform initial sphere law

The theorem uses a uniform sphere start in symmetric coordinates. A plain
Gaussian coefficient start is elliptical; it should not silently be
called uniform. One option is to redo the proof with the constant-condition
Gaussian overlap (9), changing only constants. A more literal implementation
is as follows.

Apply the explicit Legendre construction to G, whose spectrum is in the
known fixed interval [1/(1+h0),1/(1-h0)]. Obtain a FIXED polynomial J_G
approximating G^(-1/2) to relative eta0=p/(100a). This needs O(log(a/p))
G-actions, hence ~O(I), and no true square root or eigendecomposition.
Draw g~N(0,I), set c=J_G g, and G-normalize c. Its conceptual
unnormalized image y=G^(1/2)c is Gaussian with covariance eigenvalues in
[(1-eta0)^2,(1+eta0)^2]. The Gaussian KL formula gives

  KL(N(0,Cov(y)) || N(0,I)) <= O(a eta0^2).

Pinsker gives total variation at most p/10 with the displayed generous
constant. Normalization cannot increase total variation, so the starting
sphere law is within p/10 of uniform. Invoke the literal AppxPCA theorem
with failure p/2 and allocate another p/4 to all randomized inverse
solver failures. This produces a rigorous generalized implementation with
overall failure below p, at harmless extra ~O(I) work. The same coarse
whitening G is fixed across residual ranks.

6. A QUADRATIC CERTIFICATE FOR THE PROPOSED GLOBAL ABSOLUTE PENCIL

The following local block statement is proved. It explains why the
all-spectrum preconditioner idea is stronger than a bare minimum-Rayleigh
certificate, although a full rank-threshold selection algorithm is not
completed in this section.

In normalized positive-mass coordinates, suppose

  Kbar=S+E,  S=S^T, ||S||<=1, ||E||<=c h.

Choose a>=c and let Fbar=|S|+a h I. Then

  -Fbar<=Kbar<=Fbar,
  0<=Fbar-Kbar Fbar^(-1) Kbar<=C h I.                    (13)

The first inequality follows from |S|+-S>=0 and ahI+-E>=0.
For the second, note that S commutes with Fbar,
||S Fbar^(-1)||<=1, and

  0<=Fbar-S Fbar^(-1)S<=2a h I.

Expanding (S+E)Fbar^(-1)(S+E), the cross terms have norm at most
2c h, while E Fbar^(-1)E>=0. Thus the upper bound in (13) holds;
its lower bound follows from the first inequality by congruence.

Undoing the mass normalization gives

  -F<=K<=F,  0<=F-KF^(-1)K<=C h Dtilde.                  (14)

For K=t P^(-1)-Q, one may use the coarse positive mass
Dtilde=t Ptilde^(-1)+Qtilde and normalized sketch pencil
S=Dtilde^(-1/2)(t Ptilde^(-1)-Qtilde)Dtilde^(-1/2).
Relative input Gram errors imply the O(h) bound on E. Rank-deficient P
requires the usual support restriction.

Now let C=J^(-1)KJ^(-T), F=JJ^T. Suppose rank-r U is orthonormal and

  ||(I-UU^T)(I-C)||<=1+eta,  0<eta<=1/10.                (15)

For w orthogonal to U, (15) implies

  w^T(C^2-2C)w <=(2eta+eta^2)||w||^2.

Put w=J^T y. Combining with (14), and writing b=2eta+eta^2<1,

  2y^T K y >= y^T K F^(-1) K y-b y^T F y
             >=-b C h y^T Dtilde y.                      (16)

This uses the STRONG action-norm certificate (15), not merely a lower
bound on compressed C. For physical left output, dual lifting uses
the subspace A J U: if z is orthogonal to that space, y=A^T z has
J^T y orthogonal to U. Equation (16), Dtilde comparable to
tP^(-1)+Q, then gives residual norm squared <=(1+O(eta h))t.
Thus eta=Theta(theta/h), when <=1/10, is sufficient; the naive
eta=Theta(theta) loss is not necessary. Dual lifting costs O(Ir).

If t>=sigma_{r+1}(AB)^2, K has at most r negative eigenvalues and
the (r+1)-st eigenvalue of the PSD matrix I-C is at most one.
The ordinary block Krylov spectral LRA theorem can then supply (15)
in ~O(sqrt(h/theta)) block passes. A complete global algorithm still
needs a threshold selection/bracket proof without a hidden
sigma_1/sigma_{r+1} scale dependence, a charged construction of the
absolute-value proxy (or a regularized-root surrogate), and controlled
matrix-free true P^(-1) actions. Those steps are NOT asserted complete
here. The strong-cPCA/Nystrom route above bypasses this remaining
global threshold problem and already proves (A).


7. LIMITS AND NOVELTY

Strong cPCA and shift-and-invert power methods are established tools;
AppxPCA is explicitly primary prior art. This note's proved improvement
is the leakage-sensitive Nystrom counting argument and its application to
the current factored-product solver costs, not an invention claim for
cPCA or variance reduction. A global novelty comparison is still needed.
The fixed polynomial proof avoids uncharged root/eigenvalue oracles,
and exposes all precision tolerances. It does not prove floating-point
stability of the original factor whitening, canonical form, Woodbury
application, or stochastic solves. Only dedicated audit files were edited.

  D_s=sG-GQ_cG/c,

  x=D_s^(-1)Gv,

8.2 Precision, RHS growth, and all-outcome caps

The unnormalized inverse-power iterates are NOT bounded by a constant.
On good events their norms grow at most

  (C/gamma)^(C log(k/(p*^2 epsilon_pca))).

Their logarithms, source inverse-accuracy logarithms, and Euclidean/G
conversion losses are all polylogarithmic. For a zero-start normalized
SPD solve, the correct initial gap is ||b||^2/(2mu), not a constant.
The manuscript states this dependence correctly.

For a completely explicit all-outcome arithmetic cap, use the above
deterministic good-event RHS bound in the solver's planned contraction
budget, or return the current factors if an actual RHS norm exceeds it.
Also cap AppxPCA's phase count, inner epoch counts, and every required
positive normalization or denominator. Off-event divergent iterates then
do not increase runtime or demand a data-dependent extra log norm.
The UPDATED actual manuscript now explicitly uses this deterministic
Gamma RHS cap and sets the solver epoch budgets in advance. It also
chooses inverse tolerances (gamma/C)^[C log(k/(p*^2 epsilon_pca))],

The previously duplicated unnormalized-iterate sentence is fixed in
the updated manuscript.

8.3 Independent check of the NEW inverse-compression tail proof

For H positive definite, in a basis starting with z, the nonzero
Nystrom residual is the Schur complement. Its inverse is the compression
of H^(-1) to z-perp. For bottom-subspace y, the manuscript's map

  x=y-<z_tail,y> z_head/(1-w)

is injective and orthogonal to z. Its norm squared is
(1+v)||y||^2, where v=|<z_tail,y>|^2/[(1-w)||y||^2]
and v<=w/(1-w). Its inverse energy is at least
(1/t+v/lambda_1)||y||^2. The quotient decreases in v, giving the
lower bound (1-w)/t+w/lambda_1.

This constructs a (d-j)-dimensional subspace on which the compressed
inverse has Rayleigh quotient at least that bound. Min--max therefore
puts its (d-j)-th LARGEST eigenvalue above the bound. That eigenvalue
is exactly 1/lambda_j(R), because inversion reverses order. This proves
the claimed sharp tail-mass bound with the correct index. The H+epsilon I
continuity argument preserves the head/tail split and w, and rank drop
handles zero eigenvalues. This proof is independent of the secular proof

9.2 A fixed true-factor inverse-mass approximation

(h/(1-h))^(l+1)<=delta_mass, rounding the first sufficient degree up to

  (1-delta_mass)G^(-1)<=Bmass<=(1+delta_mass)G^(-1),

sum_{i=0}^l(1-g)^i=[1-(1-g)^(l+1)]/g>0. Positivity here does not assume

9.3 A uniform smooth absolute preconditioner with finite arithmetic

  D=tI+Q0, S=(tI-Q0)D^(-1).

because t(Bmass-I) lies between +-2h tI and Q-Q0 lies between
+-h Q0/(1-h), hence between +-2h Q0. No lambda_1/t factor appears.

Let a=8, M0=S^2+a^2 h^2 I, and start X_0=2I. Use exact Newton iteration

  X_{j+1}=(X_j+M0 X_j^(-1))/2.

Every iterate is symmetric and commutes with D,S. Scalar eigenvalues
rho=sqrt(m0) lie in [a h,2]; for x_j>=rho,

  x_{j+1}-rho=(x_j-rho)^2/(2x_j)<=(x_j-rho)/2.

After O(log(1/h)) predetermined steps, halving the known starting bound 2,
we have sqrt(M0)<=X<=sqrt(M0)+a h I. Materialize

and its Cholesky factor/inverse. These finite computations use arithmetic,
positive scalar square roots, and ~O(k^(omega+zeta)) work per query. This
is an exact-arithmetic operation count; D may be ill-conditioned, so no

  8hD<=F<=2D, -F<K_t<F,
  0<=F-K_t F^(-1)K_t<=36hD.                             (20)

above |S| dominates E. At Fbar0=sqrt(S^2+a^2h^2)+a h I, exactly

9.4 A positive initial quantile bracket from exact coefficients

  T_MM(s,a,s)+O(s^(omega+zeta))+T_MM(a,s,s).               (27)

Fast positive-definite Cholesky needs no spectral oracle: recursively
factor the leading block, perform one triangular solve and one matrix
product to form the Schur complement, then factor the complement.
The recurrence 2 T(s/2)+O(s^(omega+zeta)) is O(s^(omega+zeta)). All scalar
square roots are of positive numbers. Triangular inversion has the same
matrix-multiplication recurrence. Thus (27) follows from finite algebra
and scalar square roots, with no convergence or condition-number factor.

As elsewhere, this exact Gram method makes no floating-point stability
claim: conditioning is irrelevant to its real-arithmetic operation count.

10.3 Raw Krylov QR when Lraw<=m

Let Kraw be k-by-Lraw, with k<=m, Lraw=(2q+1)(r+1)<=m. Its columns may
have any dependencies. Use 10.1 to select a maximal independent subset
H=Kraw[:,J], of width d<=min(k,Lraw). Then use 10.2 to orthonormalize H.
All dimensions in (27) are at most m, hence the two products and the
Cholesky/inverse cost ~O(m^(omega+zeta)). The rank-revelation cost has
the same bound. This constructs the EXACT range basis V needed in 9.5.
It does not require generic rank, a gap, an approximate SVD, or a costly
Gram--Schmidt pass through all the raw columns.

Likewise form A_small=(T V)^T(T V) by fast multiplication, costing at
most ~m^omega, rather than the conservative O(kd^2). Exact coefficient
extraction is already bounded by ~m^omega. The final filter's k-by-r
matrix Yout has both dimensions at most m, so the same subroutine gives
ANY exact orthonormal range basis in ~m^omega, even when its rank drops.

Thus, under Lraw<=m, every small-core rank revelation, orthogonalization,
Gram, normalized Newton step, coefficient extraction, and Cholesky costs
~O(m^(omega+zeta)) per threshold query. The conservative k Lraw^2 term
in (B) is unnecessary in this parameter regime. If Lraw>m, retain the
conservative global bound or select a separately charged fallback.

10.4 Physical thin QR is bounded by the existing fast lifting cost

Let U be the independent core basis from the final filter, with width
t<=r. The physical Yphys=Z J U has full column rank. In fact this holds
even off the common embedding event: W_0 is supported in range(A^T A),
so A is injective on range(W_0); the compressed U_0 has independent
columns, and J is nonsingular because the explicit coarse F is SPD.
The exact core range basis U remains independent. Rank-zero output
simply skips this operation.

Apply (27) with a=n,s=t. The two multiplication dimensions are
(t,n,t) and (n,t,t). Tensor-dimension cyclic/transposition symmetry and
padding t<=r<=m give

  T_MM(t,n,t)+T_MM(n,t,t)<=O(T_MM(n,m,r)),
  t^(omega+zeta)<=m^(omega+zeta).

Therefore physical orthogonalization costs

  O(Acal(r))+~O(m^(omega+zeta)),

already covered by lifting and core setup. No O(n r^2) term is needed,
even in the conservative global theorem. This is consistent with the
initial support model: both use independent-column selection followed
by exact Gram--Cholesky algebra and fast multiplication.

10.5 Sharpened conditional theorem

Combining these facts with Section 9, when

  Lraw=(2q+1)(r+1)<=m, q=~O(sqrt(h/theta)),

the construction cost is simply

  ~O(I+G_h+m^(omega+zeta)+q Acal(r+1)).                   (28)

Add np+T_MM(n,r,p) for explicit output. All Gaussian repetitions are
processed independently, so their raw bases are never concatenated;
they contribute only logarithmic factors to (28), not to Lraw. The final
filter needs only a width-r block and does not keep its degree-q Krylov
basis. The condition is on the actual chosen capped per-run degree,
including its logarithms. In the example of 9.9,
Lraw=m^(11/40+o(1))<m by a fixed exponent margin, so it holds eventually
and all claimed construction/output exponents remain unchanged.

Globally one may drop the n r^2 term from (B) using 10.4 while keeping
k Lraw^2, or use (28) only under its explicit Lraw constraint. There is
no uncharged rank-revealing QR oracle in either statement.

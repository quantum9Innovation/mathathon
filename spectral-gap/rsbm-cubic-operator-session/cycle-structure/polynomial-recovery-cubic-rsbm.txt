Polynomial Recovery in the Cubic Regular Stochastic Block Model

Abstract
We consider the regular stochastic block model with two planted classes of size N , independent uniform simple 2-regular graphs inside the classes, and an independent uniform perfect
matching between them. There is a deterministic algorithm with running time bounded by a
fixed polynomial that recovers the planted partition, up to exchange of its classes, with probability 1− O(N −2 ). The main estimate is the coarse finite-field moment bound E2dimF2 ker(A−I) =
O(N 24 ). An exact configuration-model type formula and a short entropy symmetrization prove
this estimate. Binary linear algebra then reduces recovery to a polynomial number of candidate
checks with high probability. We include a complete first-moment proof of the Boolean partition rigidity needed to identify the planted candidate. The argument does not require the real
eigenspace at eigenvalue 1 to be one-dimensional.

1

Model and recovery theorem

Let V = V+ ⊔ V− , with |V+ | = |V− | = N and N ≥ 3. Independently choose a uniform simple
2-regular graph in each class and a uniform perfect matching between the classes. Their union is a
simple cubic graph G, with adjacency matrix A of order n = 2N . All asymptotic statements below
are along the integers N ≥ 3; there is no further parity restriction on N . The planted sign vector
σ equals 1 on V+ and −1 on V− . It satisfies Aσ = σ.
An equitable (2, 1) assignment is a vector τ ∈ {1, −1}n for which every vertex has two neighbors
with its own sign and one with the opposite sign. On a cubic graph this is equivalent to Aτ = τ .
Every such assignment is balanced: symmetry and A1 = 31 imply
3⟨1, τ ⟩ = ⟨1, Aτ ⟩ = ⟨1, τ ⟩,

so

⟨1, τ ⟩ = 0.

The assignments τ and −τ represent the same partition.
Theorem 1. In the model above there is a deterministic algorithm, given only G, whose running
time is bounded by a fixed polynomial in n on every input and which recovers the planted partition
with probability 1 − O(N −2 ). There is also a deterministic algorithm that lists all equitable (2, 1)
partitions on every input and has expected running time bounded by a fixed polynomial under this
model.
The proof separates two estimates. A finite-field first moment bounds the number of candidates
examined by the algorithm. A Boolean rigidity estimate says that all passing candidates represent
the planted partition with high probability. The latter estimate is proved in Appendix A.

An exact spectral version

There is also a direct rational eigenspace algorithm. Put r = dimQ ker(A − I). Reduction of integer
minors modulo two gives

Thus E2r = O(N 24 ) as well. Compute a rational basis matrix U ∈ Qn×r and choose a set J of r

v = U UJ−1 ε.
Keep exactly those v all of whose coordinates belong to {1, −1}. This lists precisely all Boolean
eigenvectors at eigenvalue 1: every vector in the eigenspace is uniquely determined by its coordinates
on J. Apply the cutoff 2r ≤ n27 to obtain a bounded-time recovery algorithm with the same
probability estimate.
This is a polynomial algorithm in the bit model, not just in a unit-cost rational arithmetic
model. Every row of A − I has four entries of magnitude one, so every minor has absolute value
at most 2n by Hadamard’s inequality. Fraction-free elimination therefore constructs a basis with
polynomial bit length. More explicitly, Cramer’s rule gives a basis with a common denominator and
numerators having O(n) bits. Writing that basis as U = V /∆, the reconstruction matrix is V VJ−1 .
Its entries have numerator and denominator bit lengths O(n2 + n log n), again by determinant
bounds. Basis construction, each reconstruction, and each sign check consequently take polynomial
bit complexity. The cutoff bounds the number of reconstructions by a fixed polynomial; without
it, their expected number is polynomial.
The spectral version needs only logarithmic real multiplicity with high probability. Neither
version asserts that dimR ker(A − I) = 1 with high probability, and the polynomial exponents here
are coarse existence bounds rather than practical running-time estimates.

Deterministic new zero eigenvalues from bipartite frame imbalance
================================================================
Root proof, November15. This distinguishes regular FRAMES from simple
regular BASE GRAPHS and must qualify any broadened old/new statement.

Let Q be a connected reversible degree frame, every row sum d>0,
whose type support is bipartite with k_L types on its left and k_R
on its right. Physical class sizes satisfy detailed balance. Summing
degrees shows that the total number m of physical vertices on each
side is equal. Every realizing undirected graph has adjacency
 A=[[0,X],[X^T,0]], X an m-by-m real matrix.

Let J embed type-constant vectors. A J=J Q, so U=im J is invariant.
Its Euclidean orthogonal complement W is invariant because A is
symmetric. Define new eigenvalues as eigenvalues of A restricted to W.

After scaling each type basis vector by its class-size square root,
the old restriction Q becomes a real symmetric bipartite matrix
 B0=[[0,S],[S^T,0]], S of size k_L-by-k_R. Put rho=rank S.
Old zero modes supported on the left and right therefore have dimensions
 z_L=k_L-rho and z_R=k_R-rho respectively.

For the full graph, the corresponding dimensions are BOTH
 z=m-rank X. Each old side's zero subspace embeds in the corresponding
full zero subspace, so z>=max(z_L,z_R). On each side, orthogonal
projection away from the old type-constant subspace leaves exactly
 z-z_L (left) and z-z_R (right)
new zero modes. Hence

 dim ker(A|W) >= 2max(z_L,z_R)-z_L-z_R
                    = |k_L-k_R|.                         (1)

This is DETERMINISTIC for every graph realizing the frame. It does not
use randomness, expansion, connectedness of the realized graph, or an
asymptotic estimate. At positive d, all nonzero-spectrum old spaces lie
orthogonally to zero spaces, so removing old zero modes on each side
does put the remaining vectors in W; no other old component is lost.

Concrete cubic example
----------------------
Take class sizes (N,3N,2N) and

 Q = [[0,3,0],
      [1,0,2],
      [0,3,0]].

All row sums are 3; detailed balance holds. Choose any simple factors:
between classes1,2 use degrees(3,1), between2,3 use degrees(2,3), and
no other edges. These exist for all sufficiently large admissible N.
The physical left side is V1 union V3, size3N; right sideV2 size3N.
Here k_L2,k_R1,rho1, so the old spectrum is {3,-3,0}, while EVERY
realizing graph has at leastONE NEW zero eigenvalue by(1).

An old zero vector has values (2,0,-1) on the three types. A new zero
vector can be chosen on V2 alone: X^T has the old left zero, so X is
singular; choose y in ker X. Since1_L^T X=3*1_R^T, sum y=0. Therefore
(0,y) is zero and orthogonal to ALL old type indicators.

Independent uniform simple factors for this Q satisfy the newly proved
general regular-frame recovery theorem. Thus the hidden 3-class frame
is recovered whp despite this unavoidable exact old/new collision.
The certified FULL-kernel algorithm handles this; an algorithm requiring
absence of every old/new collision would fail on this whole family.

Scope
-----
For a connected SIMPLE regular BASE GRAPH that is bipartite, its two
base sides have equal vertex counts, so k_L=k_R and the obstruction(1)
vanishes. This example does not refute the pending extension of complete
old/new disjointness to all simple regular bases. It DOES refute such
a claim for arbitrary reversible regular degree frames with unequal
numbers of types on the two sides.

This is a basic rank-index argument; historical novelty is not claimed.
Its purpose is an exact model qualification and a useful example of
recovery without any real eigenspace simplicity assumption.

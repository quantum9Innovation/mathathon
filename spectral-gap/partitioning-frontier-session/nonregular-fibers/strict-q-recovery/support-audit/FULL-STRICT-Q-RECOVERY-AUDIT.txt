6. Algorithm, expectation, memory and clock delta
-------------------------------------------------
Every true candidate(J,Q) is enumerated. Binary intertwiner spaces
contain all integer one-hot solutions after reduction, and every
accepted vector is rechecked over the integers with nonempty classes.
On the structural event an accepted map T is onto, so r<=k. Maximizing
r forces r=k and T a permutation. This recovers the planted partition,
its type count and its exact neighbor-count frame.

Per candidate, binary elimination costs O_K(n^3), the kernel dimension
is <=nr=O_K(n), and forming an arbitrary basis combination costs at
most O_K(n^2) bit operations. Row and class tests and integer neighbor
checks fit the same loose bound. Neighbor-count integers are O_{K,D}(1)
bits; class-size counters have O(log n) bits, as corrected explicitly
in the final source. No full list of kernel vectors is stored, so a
basis, one candidate and the best partition fit O_K(n^2) bits.

1. Precise statistical model
----------------------------
Start with N vertices in each named fiber over a known C_k. Choose one
independent uniform matching for every base edge, and apply an independent
uniform permutation of all n=kN vertex labels. Reveal the resulting
LABELED graph G and ask for the UNORDERED fiber partition. Neither fiber
names nor its orientation or a within-fiber coordinate system are targets.

Equivalently choose a uniform balanced named projection f:[n]->[k] and
then uniform matching factors. Its prior has n!/(N!)^k possible maps,
and there are (N!)^k matching choices for each. A compatible observed G
determines those matchings uniquely once f is specified. Thus
  P(f,G)=1/n!
for EVERY compatible named projection, an exact constant. This is a
particularly direct verification of the posterior; no graph automorphism
or uniform-unlabeled-multigraph assumption is involved.

For k>=4 an unordered balanced partition can have different cyclic orders
on its blocks. The named projection calculation correctly accounts for
them. It would be incorrect to declare all k! block name permutations
compatible with a fixed named C_k: exactly 2k are compatible for a
partition which covers G. This issue is handled explicitly in the proof.

2. Monodromy and component geometry
----------------------------------
Gauge the first k-1 matchings to identities along a base spanning path.
The remaining matching is a uniform permutation pi in S_N, equivalently
the composition of the original independent uniform permutations. Every
permutation cycle of length ell gives a connected lift component which
is a simple cycle of length k*ell. Hence R(G)=#cycles(pi).

This holds with no conditioning on connectedness. All resulting graphs
are simple because k>=3 and the simple base has two distinct neighbors
at every vertex. It does not include a loop base or a two-vertex
multigraph masquerading as a simple C_1 or C_2.

3. Cover-map count and ONE global Aut(C_k) quotient
--------------------------------------------------
On a component C_(k*ell), choose one vertex's base image (k choices)
and direction (2 choices). Local bijectivity forces that direction to
continue everywhere: backtracking would identify the two distinct base
neighbors. All 2k maps close and each contributes ell vertices per fiber.
The argument includes C_3, whose two neighbors remain distinct.

For R observed components there are exactly (2k)^R balanced named maps.
Two maps f,g have the same unordered fibers iff g=sigma composed with f
for ONE global permutation sigma of base vertices. Every base edge is
realized by f, so the fact that g is also a cover forces sigma to be an
automorphism of C_k. Conversely every such automorphism preserves fibers.
The dihedral group has order 2k (also equal to |S_3| when k=3). It acts
freely because f is surjective. Therefore there are exactly
  M(G)=(2k)^(R-1)
compatible unordered fiber partitions.

Repeated component lengths create no missing factorial or quotient. G
is observed on a labeled vertex set; component exchanges act on that
vertex set rather than declaring its partitions equivalent. Likewise
each component's independent phase/direction choices genuinely change
the partition except when absorbed by the same GLOBAL base automorphism.

4. Uniform posterior and exact optimal probability
--------------------------------------------------
Each compatible unordered partition contains exactly 2k compatible named
projections, all of joint probability 1/n!. Its joint probability with G
is therefore 2k/n!, independent of the partition. The posterior is uniform,
and optimal conditional Bayes exact success is 1/M(G)=(2k)^(1-R).
Choosing any compatible partition achieves this conditional probability.

For a uniform permutation of N symbols, insertion of the last symbol
gives the cycle generating recurrence F_N(t)=(t+N-1)F_(N-1)(t), F_0=1.
Therefore
  E[t^R]=t(t+1)...(t+N-1)/N!.
At t=1/(2k) the optimal unconditional success is exactly
  P_(k,N)=2k Gamma(N+1/(2k))/[Gamma(1/(2k)) Gamma(N+1)]
         ~[2k/Gamma(1/(2k))] N^(-1+1/(2k)).
It tends to zero with no restriction on the estimator's computation.
N=1 gives 1; k=3,N=2 gives 7/12; k=3,N=3 gives 91/216;
k=4,N=2 gives 9/16. These agree with exhaustive direct likelihood counts.

5. Fixed parameter, invariance, and randomized minimax qualification
-------------------------------------------------------------------
The exact expression is a Bayes-optimal success for the global-shuffle
prior in the root candidate. It is also the randomized minimax value over
all unknown balanced named projections, with the unordered partition as
target. The Bayes value upper bounds any worst-case success. For a matching
lower bound, sample a compatible unordered partition uniformly. Given
any G and compatible true parameter, its randomized success is exactly
1/M(G). For EVERY fixed hidden projection f, the random matching monodromy
is uniform on S_N, so its expected success equals the same displayed value.

Uniform compatible-partition sampling is constructive. Choose canonical
starts/orientations on the component cycles. Fix the first component's
phase/direction, then choose all remaining components' 2k phase/direction
options independently uniformly. Freeness of the global automorphism
action gives exactly one representative of each unordered partition.

There is no claim that the displayed value upper bounds every estimator
at a single specially fixed partition: an estimator can hardcode that
partition. A prior, worst-case, or invariant formulation is necessary for
the information-theoretic impossibility assertion. The root's uniform
global relabeling supplies the prior explicitly.

6. Conditioning and exact scope of the boundary
-----------------------------------------------
R=1 occurs for the (N-1)! cyclic permutations, hence with probability1/N.
Conditional on connectedness, M(G)=1 and perfect recovery is possible
FOR THE SUPPLIED known C_k. If the base size were unknown, the same
connected cycle might cover other cycle bases with orders dividing kN;
no uniqueness across those different bases is claimed.

The degree-two impossibility complements a separately audited theorem
for every fixed connected SIMPLE d-regular base with d>=3. Calling this
a sharp degree boundary is valid within that specified blind unconditioned
random-lift recovery family. It does not automatically extend to arbitrary
nonregular/unicyclic bases with decorations, growing bases, connected
conditioning, or different targets modulo graph automorphisms.

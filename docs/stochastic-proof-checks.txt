Important corrections incorporated
-----------------------------------
Every algorithmic dimension/minibatch/regularization uses computed rank
k_hat; true rank k only bounds cost. Rank k_hat<=rank(AB) holds even on
bad embedding events, so all-outcome rank caps are valid.

The A-side sampling probabilities can stay fixed; the B-side probabilities
are recomputed from fresh JL estimates of S_i L b_j at each adaptive stage.
An oblique coefficient projection need not contract individual feature norms.

The SVRG sample Hessian acts on x-x_ref using one fresh set of batches.
Independent samples on x and x_ref would destroy variance reduction.
The independent copies INSIDE the covariance product must remain independent.

Inverse right-hand sides in AppxPCA can grow within a phase. Predetermined
good-event norm bounds and stricter inverse tolerances fix all epoch counts;
abort if a norm cap is exceeded. No bad-call-dependent unbounded work or
hidden polynomial singular-value-ratio cost is used.

Coarse norm scaling now uses nu>=.9*||Qbar|| and
c=nu/[.9*(1-xi)^2], so normalized lambda_top>.84 and<=1.
All metric actions and physical lifting are charged.

The growing-rank comparison uses FAST BATCHED Krylov. An earlier draft
r=m^.1,theta=m^-.2,N=m7/6 example was rejected as an improvement example:
fast batched Krylov already fits output time there. The retained example
is r=m7/200,theta=m^-17/50,N=m7/6; its full batched basis/projection/core
accounting passed independently. Do not reuse the rejected scalar comparison.

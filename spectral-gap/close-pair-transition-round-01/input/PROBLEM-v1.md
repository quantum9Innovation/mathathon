# Close-pair transition target

Use the exact fixed-degree regular host and predetermined marked labels of SG-19 to SG-21. Let s=sqrt(m/n). The cubic model adds one vertex adjacent to the three neighbours of each marked vertex.

Determine whether the star approximation of the entire near-3 cluster and its top eigenvalue fails with nonvanishing probability when m is of order n^(1/3), and whether it fails with probability tending to one when m/n^(1/3) tends to infinity in a stated dilute range. Distinguish failure of the scalar resolvent approximation from failure of actual eigenvalue asymptotics.

Try to prove the existing cluster and eigenvector theorems under m^3/n tending to zero, removing the logarithmic loss. If that cannot be proved, state the sharpest established range and the precise obstruction.

Close-pair heuristic: expected pairs within distance r are of order m^2(d-1)^r/n. Tree resolvent interaction is of order (d-1)^(-r). Its comparison with s suggests m^3/n. This is a heuristic to test, not a premise.

All claims require explicit quantifiers, exact proof revisions, independent reviews, bounded primary-source priority checking and honest formalization scope. Preserve prior frozen files.

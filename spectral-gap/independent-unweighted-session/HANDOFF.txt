UNWEIGHTED RELATIVE FRACTIONAL EDGE UPDATES
=========================================

Main self-contained manuscript and compiled artifact:

  unweighted-degree-dichotomy.tex
  unweighted-degree-dichotomy.pdf

Fix 0 < alpha < 1. All host graphs are finite connected simple graphs,
with unit vertex masses and unit edge conductances. Precisely one
existing edge is doubled. All counts use the strict threshold > epsilon.

PROVED ORDERS

  Unit-weight paths, uniformly in size and edge position:
      supremal relative compression rank = Theta_alpha(log^2(1/epsilon)).

  Connected maximum-degree-two hosts (paths and cycles):
      the same Theta_alpha(log^2(1/epsilon)) law.

  Connected maximum-degree-three hosts:
      supremal relative compression rank = Theta_alpha(1/epsilon).
      Lower examples edit a bridge, hence leverage is exactly one.
      This also proves the order for any fixed maximum degree >= 3.
      The lower hosts can additionally be required to be BIPARTITE.

The central-edge infinite-path limit has exact count coefficient
1/(2*pi^2), independent of fixed alpha. An edge at fixed distance from
an endpoint has limiting coefficient 1/(6*pi^2). These are LIMIT-OPERATOR
coefficients, not a proved sharp coefficient for the supremum over all
finite host paths. The uniform upper coefficient proved here is only
(1+2alpha)^2/(4*pi^2*alpha).

For maximum degree d, every update has a compulsory eigenvalue
lambda_1(C_alpha) >= (1+2/(d+1))^alpha - 1. Thus arbitrary determinant-admissible
spectral closure fails at fixed degree. The weighted-path leading
count constant alpha*log(2) also cannot be attained at fixed degree,
although the 1/epsilon order already survives at degree three.
More precisely limsup epsilon*W_(d,alpha)(epsilon)
<= alpha*log[2(d+1)/(d+3)]. The stronger outlier was communicated by the
parent research thread, checked independently here by scalar Jensen,
and integrated into the final manuscript.

PROOF MECHANISMS

1. Exact path leverage z_k=(2/n)sin^2(k*pi*p/n), giving low-energy
   leverage <= sqrt(delta), plus positive pinching and scalar rational
   approximation, proves the uniform path upper bound.
2. The relative correction is between one half and one times its
   relative Frechet derivative at bridge leverage one. The derivative
   is weighted convolution with K_alpha(s)=sinh(alpha*s/2)/sinh(s/2).
   Fourier comparison reduces all alpha to alpha=1/2. Laptev's classical
   weighted-Cauchy theorem supplies the matching lower law. Midpoint
   step-kernel convergence transfers it to finite centered paths.
3. Degree-three lower examples use binary fanout, terminal necks of
   length K*m, and cubic expander reservoirs. Successive terminal
   groundings change root admittance by >=c/m, hence all reverse Schur
   pivot ratios are >=exp(c'/m). A proved separated-mass lemma converts
   them to m fractional relative eigenvalues of size >=c_alpha/m.
4. Ordinary unit-mass reservoirs realize these effective masses.
   Contact resistances persist and are included. Low/high leakage is
   O(1/s) in compressed positive powers, so relative scaling s^alpha
   still makes the error vanish for alpha<1. Only low compression is
   needed for the lower bound; high response need not vanish.
5. The bipartite strengthening uses simple cubic expander double covers
   and replaces one edge by a length-three path to create a port. Its
   gap stays >=1/(4+15/gamma_0), and sizes 4k+2 approximate every target
   mass ratio. Reservoir bipartitions can be flipped independently
   along the tree core, preserving the entire construction.

LIMITS

No sharp supremal leading constant for either degree class is claimed.
Historical priority of these precise graph-relative results is not
certified. The proofs use classical analytic and expander inputs. The
degree-three graph sizes and reservoir ratios can be enormous. No
construction runtime, compression algorithm, or finite-word stability
claim is made. Internal reviews are not external or formal verification.

Every session write is confined to this directory and its children.
Root manuscripts and other session artifacts were read only.
